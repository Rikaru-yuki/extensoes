# Extensões Project Nox

Repositório de armazenamento e publicação das extensões compiladas pelo
[Project Nox](https://github.com/Awerkori/fonte-extensoes).

Para aplicativos compatíveis com o catálogo moderno (Mihon / TachiyomiSY), adicione:

`https://raw.githubusercontent.com/Rikaru-yuki/extensoes/repo/index.pb`

(ou `https://github.com/Rikaru-yuki/extensoes/raw/repo/index.pb`)

O `repo.json` e `index.min.json` são mantidos para compatibilidade com versões legadas.
